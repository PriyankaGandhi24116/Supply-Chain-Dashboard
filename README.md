# 📦 Supply Chain Dashboard | Power BI

A dynamic and interactive Power BI dashboard designed to analyze supply chain operations through intuitive visualizations, KPIs, and business insights. The dashboard helps users monitor sales performance, inventory, logistics, and operational efficiency for better business decision-making.

---

## 1. Short Description / Purpose

The **Supply Chain Dashboard** is an interactive Business Intelligence report built using **Microsoft Power BI**. It enables users to analyze key supply chain metrics, monitor operational performance, identify trends, and make data-driven decisions through dynamic reports and visualizations.

---

## 2. Tech Stack

The dashboard was built using the following tools and technologies:

- 📊 **Power BI Desktop** – Main data visualization platform used for report creation.
- 🔄 **Power Query** – Data transformation and cleaning layer for preparing the dataset.
- 🧮 **DAX (Data Analysis Expressions)** – Used for calculated measures, KPIs, and business logic.
- 🗂 **Data Modeling** – Established relationships among tables for cross-filtering and efficient reporting.
- 📁 **File Format** – `.pbix` for dashboard development and `.png` for dashboard preview.

---

## 3. Data Source

The dashboard is built using a supply chain dataset containing information related to:

- Orders
- Products
- Customers
- Inventory
- Shipping
- Revenue
- Sales Performance

The data is modeled to provide meaningful business insights through interactive reporting.

---

## 4. Features / Highlights

### • Business Problem

Organizations often struggle to monitor supply chain performance across multiple operational areas. Important metrics such as sales, inventory, and shipping performance are scattered across different systems, making decision-making difficult.

### • Goal of the Dashboard

To provide a centralized dashboard that helps users:

- Monitor supply chain KPIs
- Analyze sales performance
- Track inventory levels
- Evaluate shipping efficiency
- Improve operational decision-making

### • Walkthrough of Key Visuals

- KPI Cards displaying important business metrics
- Sales Performance Analysis
- Revenue Analysis
- Inventory Monitoring
- Shipping Performance
- Product Performance
- Trend Analysis
- Interactive Filters and Slicers
- Executive Dashboard View

### • Business Impact & Insights

- Improves visibility into supply chain operations.
- Helps identify high-performing products.
- Supports inventory optimization.
- Enables tracking of shipping performance.
- Assists management in making data-driven business decisions.
